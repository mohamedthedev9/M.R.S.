# Brand assets: where each file came from

| File | Source | Notes |
|---|---|---|
| `mrs-wordmark-white.png` | Owner's `M_R_S_.png`, cropped, white on transparent | The **original raster** is kept for the serif wordmark. A vector trace was attempted and rejected: the hairline strokes and serifs did not survive tracing faithfully. |
| `mrs-mark.svg`, `mrs-eagle.svg`, `lib/brand-paths.ts` | **Traced** from the owner's solid `>>` + eagle raster (`image__1_.png`, 554px) | Chevrons = 2 exact polygons. Eagle = smoothed Bezier trace, verified feather-for-feather against the original at 5x. **A trace is not the designer's vector.** Replace with the original vector when available (keep ids `mrs-p-chev` / `mrs-p-eagle`). |
| `mrs-signature.png` | Extracted from the owner's "Signature" card (`M.png`) | White ink isolated from the swirl with a top-hat filter; two small dots restored by hand-picked position. |
| `../images/swirl.webp` | Owner's vortex image (file named `Gemini_Generated_Image…`), cropped so the vortex's dark eye is centred | Looks AI-generated by the owner. **Confirm you hold the rights to use it commercially.** |
| Brand gradient (`--brand-0..4`) | **Sampled** from the owner's kit posts (`mmWave_5G__4_.png`) | #f95bf6, #8f3df8, #366cf4, #1db1ef, #03f6eb. Large text and graphics only (indigo stop is 3.1:1 on black). |
| Loaders (`components/ui/Loaders.tsx`) | Rebuilt in SVG/CSS from the owner's `Loading.gif` (decelerating pill fill) and `loading-58.gif` (12 stepped spokes, 1.44 s/turn) | Motion measured frame by frame, not eyeballed. |
| Ornaments (`components/visuals/Ornaments.tsx`) | Drawn from scratch (star, sparkle, flower) + the logo's own chevrons | **Deliberately NOT lifted** from the owner's canvases: the hearts, doves, wings, squiggle, flower and star there are cropped fragments of what look like template stickers whose licence for website reuse is unknown. |
